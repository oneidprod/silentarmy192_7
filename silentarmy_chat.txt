## **🏗️ OpenCL Architecture:**

**OpenCL has TWO parts that work together:**

### **1. Host Code (C++)**
- **Runs on CPU** 
- **Manages the GPU**: device setup, memory allocation, kernel launching
- **Data transfer**: sends work to GPU, receives results back
- **Examples**: `ocl_silentarmy.cpp`, device management

### **2. Kernel Code (.cl files)** 
- **Runs on GPU**
- **Contains the actual algorithm** that executes in parallel on GPU cores
- **Examples**: input.cl, `kernel.cl` - the actual Equihash math

---
